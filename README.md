# TP API REST

Trabajo práctico de API REST desarrollado en C# y ASP.NET Core Web API.

## Funcionalidades

- Obtener mascotas.
- Buscar mascotas por ID.
- Registrar perros y gatos.
- Modificar mascotas.
- Eliminar mascotas.
- Buscar mascotas mayores a una determinada edad.
- Buscar mascotas por tipo.
